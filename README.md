# AttendTrack Website

Welcome to the **AttendTrack** promotional website! This site is designed to showcase the features of the AttendTrack ecosystem using a highly interactive, cinematic, and futuristic scroll experience.

## What is AttendTrack?
AttendTrack is a unified platform built for modern educational institutions. It replaces traditional paper-based attendance with a smart, digital ecosystem. It brings together three main roles:
- **Students:** Monitor attendance, view timetables, and submit leave requests.
- **Lecturers:** Record attendance quickly, publish notices, and review student requests.
- **Administrators:** Oversee users, courses, schedules, and bulk data imports.

## Key Features
- 📊 **Interactive Digital Attendance Grid:** Record and update attendance in seconds.
- 🗓️ **Live Schedule & Timetable:** Dynamic scheduling that automatically adapts to course enrollments.
- ✉️ **Dynamic Leave Management:** Seamless submission and approval for absence requests.
- 📢 **System-Wide Announcements:** Instant broadcasting for class changes or cancellations.
- ⚙️ **Bulk Import & Controls:** Quick onboarding with CSV/Excel uploads.

## Tech Stack
We built this website with modern tools to ensure it is incredibly fast, smooth, and visually stunning:

- **React 19**: The core framework for building the user interface.
- **TypeScript**: Adds strong typing to JavaScript, making the code safer and easier to maintain.
- **Vite**: A lightning-fast build tool and development server.
- **Tailwind CSS (v4)**: Used for rapid, responsive, and beautiful styling (including our sleek glassmorphism effects).
- **Motion (Framer Motion)**: Powers the buttery-smooth animations, fade-ins, and scroll-driven physics that bring the site to life.
- **HTML5 Canvas**: Used for the frame-by-frame cinematic scroll animation that you see right when you open the site.

## How to Run It Locally

1. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```
   This will start the site on your local machine (usually at `http://localhost:3000`).

3. **Build for production:**
   If you want to create a final, optimized version for deployment:
   ```bash
   npm run build
   ```
